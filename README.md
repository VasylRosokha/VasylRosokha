## 🤖 AI & Automation Projects

### [AI Support Email Agent](https://github.com/VasylRosokha/n8n-ai-support-email-agent)
n8n agent that answers customer support emails from a knowledge base and hands everything it can't answer safely to a human. Cheap filters before any AI call, RAG search in Pinecone, a relevance threshold measured on real scores, fallback models and an error workflow. All 15 test scenarios pass on real Gmail inboxes, including prompt injection and Gemini or Pinecone going down.  
`n8n` `Google Gemini` `Pinecone` `RAG` `Gmail API` `Docker`  
🎬 [Demo GIF in the README](https://github.com/VasylRosokha/n8n-ai-support-email-agent#readme)

### [Sheets MCP Server](https://github.com/VasylRosokha/sheets-mcp)
Remote MCP server that lets an LLM read and write real Google Sheets — 9 tools across 3 sheet layouts, built to run against messy spreadsheets that were never designed to be machine-readable. 241 tests, `mypy --strict`, CI on every push.  
`Python 3.12` `MCP SDK` `pydantic v2` `Starlette` `Google Sheets API` `Render`
